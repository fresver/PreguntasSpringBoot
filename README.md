# ❓ CRUD de Preguntas - Spring Boot + Thymeleaf

Este es un proyecto web básico hecho con **Spring Boot**, que implementa un sistema CRUD (Crear, Leer, Actualizar, Eliminar) para gestionar preguntas. El frontend está desarrollado con **Thymeleaf**, y se trata de una práctica simple pero funcional de las bases de desarrollo web con Spring.

---

## 🔧 Tecnologías usadas

- **Java 17+**
- **Spring Boot**
  - Spring Web
  - Spring Data JPA
  - Spring Boot DevTools
- **Thymeleaf**
- **H2 Database** (modo memoria para pruebas)
- **Maven**

---

## 🧠 Funcionalidades

- 📋 Listado de preguntas
- ➕ Crear nueva pregunta
- 📝 Editar pregunta existente
- ❌ Eliminar pregunta
- 🌐 Interfaz web con Thymeleaf

---

## ▶️ ¿Cómo ejecutarlo?

1. Clona el repositorio:
```bash
git clone https://github.com/TU_USUARIO/NOMBRE_REPO.git
```

2. Entra al proyecto:
```bash
cd NOMBRE_REPO
```

3. Ejecuta el proyecto:
```bash
./mvnw spring-boot:run
```

4. Abre en el navegador:
```
http://localhost:8080
```

---

## 💡 Notas

- Proyecto educativo para afianzar conocimientos de Spring Boot.
- El CRUD es básico y puede expandirse fácilmente con autenticación, validaciones o una base de datos persistente.
- La base de datos H2 se resetea cada vez que se reinicia el servidor.
